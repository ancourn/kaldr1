## 🔄 Automation Rules

### **Rule 1: Task Progress Update**
- **Trigger**: When a card's checklist is 100% complete
- **Action**: Update Progress field to 100%
- **Then**: Move card to "Done" list
- **Then**: Add "✅ Complete" label

### **Rule 2: Milestone Alert**
- **Trigger**: When a milestone card is due in 7 days
- **Action**: Send notification to card members
- **Then**: Add "🔴 Critical" label if not complete

### **Rule 3: Risk Monitoring**
- **Trigger**: When a risk card is created
- **Action**: Send notification to @Risk-Manager
- **Then**: Add "⚠️ Risk" label

### **Rule 4: Phase Transition**
- **Trigger**: When all cards in a phase list are complete
- **Action**: Send notification to @Project-Manager
- **Then**: Archive the phase list
